# Finanzierung

## 1. Kapitalbedarf

### Kernaussage
Der Kapitalbedarf einer Ferienimmobilie besteht nicht nur aus dem Kaufpreis. Zusätzlich zu berücksichtigen sind Erwerbsnebenkosten, Umsatzsteuer-Liquidität, Finanzierungskosten, Einrichtung, Renovierung, Anfangsreserve und laufende Rücklagen.

### Geltungsbereich
- Land: Österreich
- Finanzierung: Immobilienkauf, Hypothekarkredit, Eigenkapital, Fremdkapital
- Keine konkrete Kreditberatung

### Quelle
- Quelle: Nebenkosten beim Wohnungs- und Grundstückskauf
- Herausgeber: oesterreich.gv.at
- Link: https://www.oesterreich.gv.at/de/themen/bauen_und_wohnen/wohnen/8/Seite.210150
- Stand/Veröffentlichungsdatum: Website, laufend aktualisiert
- Abrufdatum: 2026-05-15
- Geltungsbereich: Österreich
- Stabilität: mittel
- Aktualisierung nötig bei: Änderung Gebühren, Maklerrecht, Finanzierungsstruktur

### Allgemeine Kapitalbedarfsformel
```text
Gesamtbedarf =
Kaufpreis
+ allfällige Umsatzsteuer
+ Grunderwerbsteuer
+ Grundbuchgebühr
+ Pfandrechtseintragung
+ Vertragserrichtung / Treuhand / Notar / Rechtsanwalt
+ Maklerprovision
+ Bankspesen
+ Einrichtung / Inventar
+ Renovierung / technische Anpassungen
+ Anfangsreserve
+ laufende Betriebsmittelreserve
```

- Umsatzsteuerpflichtiger Kauf?
- Darlehenshöhe?
- Pfandrecht?

- Reserve für Leerstand und Reparaturen?

## 4. Kreditnehmerstruktur

### Kernaussage
Die Wahl des Kreditnehmers ist eine zentrale Strukturfrage. Kreditnehmer können natürliche Personen, Miteigentümer, eine Personengesellschaft oder eine Kapitalgesellschaft sein. Banken verlangen häufig zusätzliche Sicherheiten oder persönliche Haftungen.

### Geltungsbereich
- Land: Österreich
- Beteiligte: mehrere Eigentümer oder Gesellschaft
- Finanzierung: Bankkredit, Sicherheiten, Bürgschaften

### Quelle
- Quelle: Gesellschaftsformen-Informationen
- Herausgeber: Wirtschaftskammer Österreich
- Link: https://www.wko.at/wirtschaftsrecht/gesellschaft-buergerliches-recht-gesbr
- Link: https://www.wko.at/wirtschaftsrecht/kommanditgesellschaft-kg
- Link: https://www.wko.at/wirtschaftsrecht/gesellschaft-mit-beschraenkter-haftung-gmbh
- Stand/Veröffentlichungsdatum: Websites, laufend aktualisiert
- Abrufdatum: 2026-05-15
- Geltungsbereich: Österreich
- Stabilität: mittel

### Vergleich

| Kreditnehmer | Vorteile | Nachteile / Risiken |
|---|---|---|
| alle Miteigentümer persönlich | Bonität aller nutzbar, einfache Besicherung | gesamtschuldnerische Haftung, Konflikte bei Ausstieg |
| GesbR / Miteigentümerstruktur | vertraglich flexibel | keine eigene Grundbuchfähigkeit der GesbR, persönliche Haftung |
| KG | klare Gesellschaftsstruktur | Komplementärhaftung, Bank verlangt ggf. Sicherheiten |
| GmbH | einheitlicher Kreditnehmer, professionelle Außenwirkung | neue GmbH ohne Historie oft schwach; Bürgschaften wahrscheinlich |
| GmbH & Co KG | strukturierbar für Investoren | komplexer, höhere Kosten, bankseitig erklärungsbedürftig |
